# Release checklist

- [ ] Stage and authenticate the external artifact archive.
- [ ] Run and retain bounded production manifests for Goals 6–9.
- [ ] Resolve v2 verifier/compiler ownership and exact-SR verifier scope.
- [ ] Obtain correct MIT copyright holder/year before adding `LICENSE`.
- [ ] Obtain credentials and explicit spend approval before LLM panel calls.
- [ ] Run fresh-clone reproducibility verification.
- [ ] Recheck the [official MathNLP 2026 site](https://sites.google.com/view/mathnlp2026) and
      OpenReview submission requirements immediately before submission; the currently published
      direct-submission deadline is 31 July 2026 (Anywhere on Earth).
- [ ] Verify every paper claim/table/figure against a checksum-authenticated final-report row;
      planning rows and phase-A contracts are not empirical evidence.
